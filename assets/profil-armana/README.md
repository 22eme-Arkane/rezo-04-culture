# Kit Profil Armana

Tous les éléments sont indépendants et redimensionnables sans perte.

## Éléments de structure

- `flag-yellow.svg` : titre « Créer & gérer ».
- `flag-blue.svg` : titre « Communauté & administration ».
- `flag-green.svg` : titres « Pratique » et « Assistance ».
- `timeline-connector.svg` : trait vertical reliant les drapeaux et les pastilles.
- `icon-chevron.svg` : chevron placé à droite de chaque ligne.

Les titres des sections restent du vrai texte HTML superposé aux drapeaux afin de
conserver l’accessibilité et une bonne adaptation aux petits écrans.

## Faire un don

- `donation-card-background.svg` : fond jaune, logo officiel en filigrane et triangle bleu.
- `donation-card-complete.svg` : version de référence complète avec cœur, texte et flèche.
- `icon-don-heart.svg` et `icon-arrow-round.svg` : éléments séparés pour une intégration interactive.
- `armana-logo-officiel.png` : véritable logo, jamais une régénération.

Le fond seul est recommandé dans l’application : le texte « Faire un don » et les
icônes restent alors de vrais éléments interactifs et accessibles.

## Couleurs

- Vert : `#064f36`
- Jaune : `#ffc400`
- Bleu : `#0b55c5`
- Crème : `#fff4df`

## Pastilles d’actions

Les fichiers `icon-*.svg` couvrent les écrans utilisateur et administrateur,
y compris les modérateurs, les candidatures et la navigation inférieure.
