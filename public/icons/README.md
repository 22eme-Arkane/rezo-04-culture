# Icônes PWA

Placez ici deux icônes (référencées par `manifest.webmanifest` et `index.html`) :

- `icon-192.png` — 192×192 px
- `icon-512.png` — 512×512 px

Fond conseillé : `#0c0e1a`. Prévoir une marge de sécurité pour le rendu `maskable`
(le logo ne doit pas toucher les bords). Tant qu'elles sont absentes, l'installation
PWA fonctionne mais sans icône dédiée.
